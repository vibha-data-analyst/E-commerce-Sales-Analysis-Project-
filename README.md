# E-commerce-Sales-performance -Analysis-

Project Overview

This project focuses on analyzing e-commerce sales data using Tableau to understand sales performance, product popularity, and customer purchasing patterns.

Objectives

- Analyze overall sales performance.
- Identify the top 10 best-selling products.
- Compare sales across different countries.
- Analyze monthly revenue trends.

Tools Used

- Tableau
- Microsoft Excel
- Kaggle Dataset

Key Findings

- Total Orders: 22,062
- Highest Sales Country: United Kingdom
- Top 10 best-selling products identified.
- Monthly revenue trends analyzed.

Project Files

1. E-commerce Sales Performance Analysis PDF
2. Tableau Dashboard PDF

Project Status

Completed

Conclusion

This project helped analyze e-commerce sales performance and understand how data visualization can support better business decisions.
